# HuntaBot
Личное Android-приложение (AccessibilityService) для Instagram: подписки с аккаунтов-доноров,
активность (истории/лайки/комменты) только на тех, на кого подписался бот, и еженедельная отписка.

## Сборка APK через GitHub
1. Создай репозиторий на GitHub и залей все файлы этого проекта (ветка main).
2. Вкладка Actions → Build APK → дождись зелёной галочки (или Run workflow).
3. Внутри запуска → Artifacts → HuntaBot-apk → скачать, распаковать zip → app-debug.apk.
4. Перекинь APK на телефон и установи.

## Настройка на Redmi Note 8 (MIUI)
- Настройки → Приложения → HuntaBot → Автозапуск: ВКЛ; Экономия энергии: «Нет ограничений»;
  «Другие разрешения» → «Показывать всплывающие окна, когда приложение работает в фоне»: ВКЛ.
- Если спецвозможности недоступны (серый переключатель): О приложении → ⋮ → «Разрешить ограниченные настройки».
- Настройки → Расширенные → Спецвозможности → HuntaBot → включить.
- Instagram на английском языке. Телефон на зарядке, экран включён.
